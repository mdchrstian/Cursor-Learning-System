description: Start a learning session on a topic
---

Start a learning session. The topic is everything after the command.

1. Follow `.cursor/skills/teach/SKILL.md`. Read it if it is not already in context.
2. Topic folder: `Topics/<Name>/`. Reuse the folder if it exists. Name it in a few words; use hyphens for spaces (`TCP/IP` becomes `TCP-IP`).
3. Create the next `Session-NN.md` (two digits) by copying `_templates/Session.md`. Fill `topic`, `session`, and today's date, and set the heading to `<Name> — Session NN`. Stop there. Do not write the conversation into the file. Creating this file is what attaches the transcript logger to this chat.
4. If `Notes.md` does not exist, copy `_templates/Notes.md` and set the topic title. If `progress.md` exists, read that file only, so mastered ideas are not re-taught. Do not open older session files.
5. Explain in the first teaching reply. Do not ask a question before that explanation. A check question comes only after the explanation and a worked example.
