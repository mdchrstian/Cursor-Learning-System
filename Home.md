# Learning

This folder is an Obsidian vault. Open it in Obsidian and the session files render with callouts, math, and diagrams. Adapted from [amosblomqvist/learn](https://github.com/amosblomqvist/learn), trimmed so teaching stays cheap on tokens.

## How to use

- `/learn <topic>` starts a topic, or adds another session to one you already have.
- `/wrap` saves a short progress file. Do this about every 30–40 turns.
- `/resume <topic>` in a **new chat** continues from that progress file.

The transcript writes itself into the session file. The study note (`Notes.md`) gains the plan when teaching starts, and each concept just after it is explained. Open that note in Obsidian for rendered math. The chat shows the same math as plain text, because Cursor does not render LaTeX.

## Spend fewer tokens

- Use a mid-tier model. The teaching skill carries the method.
- Keep one topic per chat. Wrap, then resume in a fresh chat, instead of letting one chat grow forever.
